## Problem

A potato cooperative in Musanze needs an evidence-based decision-support tool
that can:

1. **Estimate harvest quantity** (regression on `yield_tons`).
2. **Identify farms at high production risk** (classification on `high_risk`,
   defined as yield per hectare below the dataset median).
3. **Group farms with similar conditions** (clustering on farm-condition
   features only — never on targets).

Internet access may be unreliable, so training and command-line prediction run
fully locally. A FastAPI service exposes validated inference for later mobile
integration.

## Responsible AI

- **Intended use:** classroom decision-support prototype for teaching ML
  pipelines; illustrative yield/risk estimates for a Musanze cooperative demo.
- **Not for:** replacing an agronomist; determining access to finance,
  insurance or public services; any real-world operational decision.
- **Data:** 100% synthetic; no personal or farm data is included.
- **Risks:** simulated relationships may not transfer to real agronomy;
  performance measured on synthetic noise levels only.
- **Human review required:** every prediction must be reviewed by a qualified
  field officer or agronomist before any action.

## Limitations

- Synthetic formula-driven targets; real yield depends on pests, soil type,
  timing and market factors not modelled here.
- Small dataset (264 rows); metrics have wide uncertainty.
- Clusters describe the generated feature space only.
